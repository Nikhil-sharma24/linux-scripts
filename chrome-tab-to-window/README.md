# Move Tab to New Window - Chrome Extension

**Alt+Down**: Move tab to new window  
**Alt+Up**: Restore tab to original window

## Install

1. Open Chrome/Brave
2. Go to `chrome://extensions/` (or `brave://extensions/`)
3. Enable "Developer mode" (toggle in top right)
4. Click "Load unpacked"
5. Select the `chrome-tab-to-window` folder
6. Done!

## Usage

1. **Alt+Down** - Moves current tab to a new window (remembers where it came from)
2. Then **F11** - Fullscreen it (GNOME extension moves it to new workspace)
3. **Alt+Up** - Restores tab back to the original window (closes the single-tab window)

If the original window is closed, Alt+Up will merge into any available window.
